## Devpost submission form — exact fields

These are the literal fields on the draft submission wizard, read from the live form.

### Step 1 — Project overview
- `Project name` — required, **60 character limit**
- `Elevator pitch` — required, **200 character limit**
- `Thumbnail` — JPG / PNG / GIF, 5 MB max, 3:2 ratio recommended

### Step 2 — Project details
- `* About the project`
- `* Built with`
- `"Try it out" links`
- `Image gallery`
- `Choose files`
- `Video demo link`

Field notes:
- `About the project` — Markdown with LaTeX support. Devpost's own placeholder prompts for **Inspiration / What it does / How we built it / Challenges / Accomplishments / What we learned / What's next**.
- `Built with` — tag list, **max 25 tags** (languages, frameworks, platforms, cloud services, databases, APIs).
- `Try it out links` — repeatable URL field for demo site, app store listing, or GitHub repo.
- `Image gallery` — JPG / PNG / GIF, 5 MB max each, **up to 15 images**, 3:2 ratio recommended.
- `Video demo link` — must be a **YouTube, Facebook Video, Vimeo or Youku** URL. Embedded at the top of the project page.

## What to build / Requirements

Submission Requirements 
To qualify for judging, each submission must include:

- 
A publicly accessible website link

- 
A project description explaining your idea and inspiration

- 
At least 3 screenshots of your project

- 
A short demo video (1–5 minutes) (Optional)

- 
A list of technologies and tools used

- Source code

 Requirements 
• Project must be web-based

• Project must contain meaningful 3D or immersive visual elements

• AI-generated content and assets are allowed

• Existing assets and models are allowed

• Teams and solo participants are both welcome

• Projects must be appropriate for all audiences

 Technologies You Can Use (Not limited to): 
• Three.js

• React Three Fiber

• Babylon.js

• Blender

• Spline

• WebGL

• WebGPU

• GSAP

• Framer Motion

The goal is not technical difficulty.

The goal is to create the most memorable experience possible.

## Judging criteria

- 
 Visual Design

 How polished, appealing, and visually impressive is the project? Consider composition, color, lighting, typography, animations, and overall presentation.
 

 - 
 Creativity & Originality

 How unique is the concept? Does the project present ideas, interactions, or experiences in a way that feels fresh and memorable?
 

 - 
 User Experience & Interactivity

 How enjoyable is the project to explore? Consider navigation, responsiveness, engagement, and the quality of user interactions.
